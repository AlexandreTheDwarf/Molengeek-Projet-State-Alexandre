## Introduction

Ce projet est une application de formulaire d'abonnement développée avec React. Le but de ce projet est de valider nos compétences sur l'utilisation des hooks `useState` en React. L'application permet aux utilisateurs de choisir un plan d'abonnement (mensuel ou annuel) et d'ajouter des options supplémentaires.

## Fonctionnalités

- Sélection de plans d'abonnement (Arcade, Advanced, Pro)
- Choix entre abonnement mensuel ou annuel
- Ajout d'options supplémentaires (Online Service, Larger Storage, Customizable Profile)
- Résumé des choix avec calcul du prix total
- Validation et confirmation des choix

## Installation

Pour installer et exécuter ce projet localement, suivez ces étapes :

1. Clonez le dépôt :

```bash
git clone https://github.com/AlexandreTheDwarf/Molengeek-Projet-State-Alexandre
cd Molengeek-Projet-State-Alexandre
```

2. Installez les dépendances :

```bash
npm install
```

3. Lancez l'application :

```bash
npm run dev
```

L'application sera accessible à l'adresse `http://localhost:3000`.

## Utilisation

1. **Étape 1 : Informations personnelles**
   - Remplissez vos informations personnelles (nom, email, numéro de téléphone).

2. **Étape 2 : Sélection du plan**
   - Choisissez un plan d'abonnement (Arcade, Advanced, Pro).
   - Sélectionnez la durée de l'abonnement (mensuel ou annuel).

3. **Étape 3 : Ajout d'options supplémentaires**
   - Ajoutez des options supplémentaires (Online Service, Larger Storage, Customizable Profile).

4. **Étape 4 : Résumé**
   - Vérifiez vos choix et le prix total.
   - Vous pouvez revenir en arrière pour modifier vos choix.

5. **Étape 5 : Confirmation**
   - Confirmez vos choix pour finaliser l'abonnement.

## Technologies utilisées

- **React** : Bibliothèque JavaScript pour construire des interfaces utilisateur.
- **SCSS** : Préprocesseur CSS pour styliser l'application.
- **useState** : Hook React pour gérer l'état local des composants.
